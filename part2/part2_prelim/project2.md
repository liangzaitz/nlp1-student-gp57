4) idea for a more complex semantic feature: we can test whether, for some threshold value between -1 and 1, an H-sentence embedding in the training set being this close or closer to an H-sentence embedding in the test set, is predictive of correct classification. The idea is that if this feature is predictive, then basically the more similar a (embedding of a) sentence in the test set is to some (embedding of a) sentence that the model has seen in training, the better it is at predicting it. So this will be a binary feature (does the test sentence have a 'sibling' in the training set? yes/no, and is this predictive of correct classification?) How to code it up: (i) decide on threshold on what counts as 'close enough to be interesting'; (ii) use cos_similarity or some other function to search for the closest sentence in the training set, for each test set sentence; (iii) note label and predicted class for each such H-H-sentence pair, and evaluate whether the feature is predictive.
